🚀 Cara Menjalankan Website

Website ini dibuat dengan React (Vite) dan membutuhkan server lokal untuk berjalan.

Buka terminal/command prompt di dalam folder project ini, lalu jalankan perintah:

npm run dev

Setelah server berjalan, klik tombol di bawah ini untuk melihat hasilnya langsung di halaman ini.
